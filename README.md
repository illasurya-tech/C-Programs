# C++ Programming Practice

## 📌 About This Repository

This repository contains a collection of **simple and beginner-friendly C++ programs** developed to practice and understand the fundamental concepts of C++ programming. The programs are designed to improve programming logic, problem-solving skills, and understanding of Object-Oriented Programming (OOP).

The repository includes programs based on mathematical problems, functions, classes and objects, constructors and destructors, inheritance, virtual functions, templates, lists, and other important C++ concepts.

These programs are useful for **students, beginners, and anyone who wants to practice C++ programming from basic to intermediate level**.

---

## 🎯 Objectives

The main objectives of this repository are:

- To understand the basics of C++ programming.
- To improve logical and problem-solving skills.
- To practice Object-Oriented Programming concepts.
- To understand classes and objects.
- To learn constructors and destructors.
- To understand different types of inheritance.
- To learn virtual functions and runtime polymorphism.
- To understand templates and generic programming.
- To implement list data structures and their operations.
- To develop simple and easy-to-understand C++ programs.

---

## 🛠️ Concepts Covered

The programs in this repository cover the following concepts:

### 1. Basic C++ Programming

- Variables and data types
- Input and output
- Operators
- Conditional statements
- Loops
- Functions

### 2. Mathematical Programs

Programs based on mathematical calculations and problem solving, including:

- Finding the roots of a quadratic equation
- Arithmetic operations
- Formula-based calculations
- Logical and numerical problems

### 3. Classes and Objects

The repository contains programs demonstrating the use of:

- Classes
- Objects
- Data members
- Member functions
- Access specifiers
- Encapsulation

### 4. Constructors and Destructors

Programs are included to understand:

- Default constructors
- Parameterized constructors
- Constructor execution
- Destructor execution
- Object creation and destruction

### 5. Inheritance

Different types of inheritance are practiced, such as:

- Single inheritance
- Multilevel inheritance
- Multiple inheritance
- Hierarchical inheritance

Inheritance helps in understanding how properties and functions can be reused between classes.

### 6. Virtual Functions

Virtual function programs demonstrate **runtime polymorphism** in C++. They help understand how a base class pointer can call the appropriate derived class function during program execution.

### 7. Templates

Template programs demonstrate **generic programming** in C++. Templates allow the same function or class to work with different data types.

The repository includes examples of:

- Function templates
- Class templates

### 8. List and List Operations

Programs are included to understand lists and their basic operations, such as:

- Creating a list
- Inserting elements
- Deleting elements
- Displaying elements
- Searching elements
- Performing basic list operations

## ▶️ How to Run the Programs

### Step 1: Clone the Repository

```bash
git clone <your-repository-link>
```

### Step 2: Open the Project

Open the downloaded repository folder in your preferred C++ IDE or Visual Studio Code.

### Step 3: Compile the Program

Using G++:

```bash
g++ program.cpp -o program
```

### Step 4: Run the Program

On Windows:

```bash
program.exe
```

On Linux/macOS:

```bash
./program
```

You can also directly run the programs using an online C++ compiler.
